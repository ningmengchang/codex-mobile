# 会话终端

## 使用

在具体聊天顶部点击 `›_`，自动连接或恢复终端。首次在当前浏览器或 APP 确认权限说明后会记住，不需要每次点连接；取消首次确认不会创建终端。终端初始目录由服务端读取会话决定，不接受浏览器任意指定路径。顶部只显示初始目录短名，完整路径保留在 title 中；在 Shell 执行 `cd` 后目录名不跟随更新，可用 `pwd` 确认实际位置。

- 终端支持交互式 Bash、Tab、上下历史、Esc、Enter、Ctrl+C 和全屏终端程序。
- 在终端光标处直接输入，点击顶部“键盘”可主动唤起输入法。没有独立命令框或“运行”按钮，回车按真实终端行为发送给当前程序，不逐条确认。首次连接不强制弹出软键盘。
- 手机端铺满可视区域，深浅主题与应用一致。根据 Visual Viewport 调整高度，避免键盘高度重复扣除；横屏使用紧凑字号。
- 在终端正文上单指上下拖动查看缓存输出：向下拖看更早记录，向上拖看较新记录。查看历史时新输出不强行拉回底部；连续拖动、横屏和键盘缩小视口均可用。滑动不唤起键盘、不发送方向键，也不触发聊天页面切换。
- 全屏终端程序使用自己的备用屏幕，没有普通 Shell 的历史缓存。若程序开启了鼠标滚动协议，拖动会转换为滚轮事件；未开启时不模拟按键，避免误操作命令行。桌面鼠标滚轮和文字选择保持原行为。
- 顶部“⋯”可按需展开 Ctrl+C、Tab、Esc、方向键、Enter，不常驻占用空间。
- 返回聊天或按 Android 返回不会结束任务；重新打开同一会话自动恢复终端。“⋯ → 结束终端”并确认会终止该终端及其子进程。
- 每个配对登录最多 4 个终端，整个服务最多 12 个。无输入输出 30 分钟或存活 8 小时自动回收；服务重启会结束终端。不同 Agent、不同会话和不同配对登录隔离，不能读取彼此的终端输出。
- “⋯ → 输出交给 AI”优先使用选中文本，否则提取最近 160 行、最多 12000 字符。用户检查并编辑后放入原聊天草稿，保留原草稿，不自动发送。仅作常见凭据脱敏，不能保证识别所有秘密。
- 已移除常用命令、参数表单、收藏入口和相关前端请求。旧版 `terminal-workflows.json` 及其兼容接口保留，不删除用户收藏数据。
- 连接失败在终端页内重试；已结束的终端可明确点击“重新开启”。不要为断网重复按回车，网络重试沿用相同输入序号去重。

## 权限边界

这是手动终端，不是 AI 工具审批：它直接以服务的普通用户运行，拥有该用户的文件和命令权限。允许目录只限制初始目录，不是 Shell 沙箱，用户仍可 `cd` 到其有权限访问的其他目录。root 服务拒绝启动终端。首次连接明确说明并要求确认，之后在此浏览器保存版本化的知情确认记录；服务端仍校验 acknowledged。直接在终端键入的按键按真实终端工作。

所有接口要求现有配对会话，写入检查同源，终端会话按登录 SID 与 Agent 双重绑定。输入按序号去重，断线重试不会重复执行同一次输入。Shell 环境仅带基础变量，不继承网关密钥或模型 API Key；不加载 `.bashrc`，不保存到用户的 `.bash_history`。Shell 中 `codex` 是主账号入口；需要其他账号时明确使用 `codex1`、`codex2`、`codex-ds`、`codex-glm`。本功能不修改这些入口或登录文件。

## 实现与性能

- `server/terminal.mjs`：会话隔离、生命周期、输入顺序、每终端 256 KiB 输出环形缓存。
- `server/terminal-pty.py`：Python 3 标准库 PTY，支持窗口尺寸和进程清理；不依赖 node-pty 原生编译。
- `server/terminal-workflows.mjs`：旧版常用操作兼容接口与原子持久化，新前端不再调用。
- `public/js/terminal.js`：终端页面、自动连接、一次性知情确认、直接输入、输出检查与 AI 草稿。
- `terminal-utils.js`：输出脱敏；模板校验仍供旧版兼容接口使用。
- `public/terminal.css`：紧凑布局；适配视口高度、键盘与横屏。
- xterm.js 6.0.0 / addon-fit 0.11.0 来自 npm 官方包，本地托管并随附 MIT 许可证。只在打开终端时加载，不增加聊天初始化的脚本负担。
- 输出仅在面板可见且应用处于前台时每 500ms 增量拉取；等待渲染完成后才继续拉取，浏览器最多保留 1200 行。

## 验证与部署

运行 `npm run verify` 和 `npm run test:terminal`。后者需要 Playwright，可通过 `PLAYWRIGHT_PATH` 指向已安装包。测试使用临时目录和独立端口，不使用生产会话或账号。

首次安装必须包括服务端模块、`terminal-pty.py`、前端模块、`terminal.css`、`public/vendor/xterm*` 以及入口和 Service Worker。本次纯终端改版仅更新前端资源，无需重启服务或重装 APK；Android 现有返回桥按最上层 dialog 关闭页面。

回归包含真实 PTY、一次性确认、取消、失败重试、直接键入、中文组合输入、粘贴、退格、历史、Ctrl+C、自动恢复、深浅主题和视口缩放。目前不含 Warp 式自动命令分块、团队云工作流或多 Agent 统一编排。浏览器模拟的中文组合输入与视口测试不能替代真机输入法和后台行为验收。
